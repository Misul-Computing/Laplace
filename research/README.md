# Research archive

Experiments, design notes, and historical measurements live here. They record
work in progress and earlier runtime designs; they are not the current product
support contract.

Start with the repository [README](../README.md) to build and use Laplace,
[current support](../docs/support.md) for running capabilities and known gaps,
and [benchmark guidance](../docs/benchmarks.md) for new measurements.

The `laplace_kv/` directory contains cache experiments, protocols, corpus
fixtures, and their results. Historical CLI tools live in `laplace_kv/legacy/`. Top-level reports and architecture notes preserve
the context behind earlier decisions. Commands and performance figures in
these files apply to the revisions and setups they describe.
